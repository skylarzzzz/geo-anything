# 八类场景的具体做法

<a id="s1"></a>
## S1 网站 / 工具 / SaaS

**必做**
- 首页首屏一句话定义：是什么 + 给谁 + 解决什么。
- 做一个「常见问题」区块，5–10 个问题式标题，每个回答 2–4 句，第一句即答案。
- 「和 XX 有什么区别」对比页或对比段落（用表格）。
- 确认正文无需执行 JS 就能被抓取；纯前端渲染的站点考虑预渲染/静态导出，或至少把核心介绍写在 HTML 里。
- llms.txt、JSON-LD（WebSite + SoftwareApplication/Organization + FAQPage）、完整 title/description/OG。
- robots.txt 不要误挡 AI 搜索爬虫（OAI-SearchBot、ChatGPT-User、PerplexityBot、Claude-SearchBot 等）。

**加分**
- 一篇「方法论」文章，给你的做法起一个可被引用的名字。
- 更新日志页（体现活跃与新鲜度）。

<a id="s2"></a>
## S2 GitHub / 开源项目

- About：≤120 字符，「是什么 + 给谁 + 核心关键词」。
- Topics：6–12 个，含品类词（如 claude-skill、codex-skill、generative-engine-optimization）和场景词。
- README 顺序：一句话定义 → 效果截图/GIF → 30 秒上手 → 能做什么（列表）→ FAQ（问题式）→ 与同类项目对比 → 作者与链接。
- 中英双语首段：中文 AI 读中文，海外 AI 读英文。
- 发 Release 并写清楚变更（新鲜度信号）。
- 外部提及：在掘金、CSDN、知乎、V2EX、小红书、X、Reddit、Hacker News 等写真实的使用教程，链接回仓库。被 awesome 列表收录是很强的信号，可以按其规则提交 PR。

<a id="s3"></a>
## S3 社媒内容（小红书 / 抖音 / 公众号 / 知乎 / B 站）

> 小红书的完整打法见 references/xiaohongshu.md，抖音、微信、知乎等内置 AI 见 references/embedded-ai.md。

- 标题：问题式或「数字 + 结果」，包含用户会问 AI 的关键词。
- 正文第一段直接给结论，结尾一句话总结（AI 常摘首尾）。
- 视频：字幕、标题、简介里写出关键结论文字；抖音、B 站简介写清步骤。
- 同一主题在多个平台各发一次，措辞一致的定义句。
- 知乎回答、公众号长文适合放完整方法；小红书适合放清单与对比图。
- 账号简介写清「我是谁 + 我持续分享什么」。

<a id="s4"></a>
## S4 个人品牌

- 生成长（≤200 字）、中（≤80 字）、短（≤30 字）三版自我介绍，全平台统一名字写法。
- 每个主张都配证据：作品链接、项目、数据、获奖。
- 入口清单：个人网站或主页、GitHub、领英/脉脉、小红书/抖音/B 站简介、知乎、简历。
- 写 1–3 篇「代表作说明」文章，标题包含「职位/领域 + 你做成的事」。
- 求职场景：想象招聘方会问 AI「做过 XX 的 AI 产品经理」，确保有页面能回答。

<a id="s5"></a>
## S5 电商 / 出海商品

- 先写品类定义内容，而不只是商品页：「什么是 X」「怎么挑 X」「X 去哪买」。
- 商品页：Product + Offer + 真实的 AggregateRating（只能用真实评价）。
- FAQ：材质、尺寸、运费、时效、退换、是否手工。
- 社区提及：Reddit、小红书、Instagram、TikTok、垂直论坛的真实分享，遵守各社区规则，不刷帖。
- 出海时英文内容要地道，避免机翻；把原产地、手工等差异点写清楚。

<a id="s6"></a>
## S6 本地商家

- 高德、百度地图、大众点评、美团、Google Maps 上的名称、地址、电话、营业时间完全一致。
- 官网或公众号写 FAQ：价格区间、是否需要预约、停车、适合人群。
- LocalBusiness schema。
- 鼓励真实顾客评价（不买评价）。

<a id="s7"></a>
## S7 B2B / 制造业企业

- 问题池以「选型」为核心：「XX 设备怎么选」「XX 工艺供应商有哪些」「A 和 B 方案对比」。
- 产品页给出参数表、适用工况、认证、交付周期、案例。
- 白皮书、行业报告、原始数据（AI 偏爱一手资料），标明作者与日期。
- 外部提及：行业媒体、百科词条、展会报道、协会名录、招投标公开信息。
- Organization + Product schema，公司全称、简称、英文名统一。

<a id="s8"></a>
## S8 知识 / 课程 / 内容 IP

- 给方法论命名，并在所有地方用同一个名字和定义句。
- 每个核心概念一篇问答式短文。
- 课程页：大纲、适合谁、学完能做什么、讲师背景（Course + Person schema）。
- 在知乎、公众号、B 站等长内容平台建立「概念原始出处」。
