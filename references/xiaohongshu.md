# 小红书 GEO 手册：让「问一问」和「点点」引用你的笔记

> 依据：公开报道与行业文章（2024–2026），以及小红书社区规范，具体来源见 ACKNOWLEDGEMENTS.md。平台没有公开排序规则，以下机制为经验总结，部分来源出自 GEO 服务商，带有推广性质，请以实测为准。

## 一、两个 AI 入口，优化重点不同

| | 问一问 | 点点 / 问点点 |
|---|---|---|
| 入口 | 搜索一个问题后，搜索结果页右上角 | 站内搜索框下方的提示入口，另有独立 App、微信小程序、PC 端 |
| 模型（据报道） | 接入千问 | 小红书自研模型，早期测试接入过 DeepSeek |
| 答案形式 | 把多篇笔记合成一段答案，**署名标注**引用了哪位作者的笔记 | 多轮对话、拍照提问；以小红书笔记为主，也会引用其他平台 |
| 用户意图 | 主动搜索，购买意图强 | 生活决策、避坑、出行、美食、购物 |
| 优化核心 | 笔记**被引用并署名** | 笔记**被检索**，并在多轮追问中被命中 |
| 额外机会 | 可以在问一问里给问题「写回答」 | — |

答案生成的大致流程：理解问题 → 检索匹配笔记 → 多篇整合 → 标注来源。所以要同时做到两件事：**被检索到**（语义匹配）和**被选中摘录**（内容好抽取、可信）。

## 二、被检索到：让 AI 知道你的笔记在回答哪个问题

1. **标题写成完整的问题或答案**，而不是关键词堆砌。
   - 弱：「油皮护肤｜平价好物」
   - 强：「油皮夏天用什么防晒不闷痘？我实测了 6 款」
2. **建立问题地图**：按认知（场景问题）、决策（对比、测评）、转化（品牌确认）三层，每层准备 5–10 个问题，一篇笔记只主答一个问题。
3. **挖真实问题**：小红书搜索框下拉联想、问一问里已有的问题、相关笔记的高赞评论、竞品笔记评论区的提问。
4. **话题标签**：优先选新出现的问题类话题（竞争小），再选高热话题，最后选垂直话题；不堆砌无关标签。
5. **关键词自然出现在正文**，堆砌反而会被语义检索降权。

## 三、被选中摘录：让 AI 愿意引用你

1. **前 50 字给结论**：AI 优先读取开头，第一句直接回答标题的问题。
2. **分点、有数据**：用 1/2/3 编号；写清具体数字（价格、时长、尺寸、步骤数、实测结果）。
3. **图片里的字也会被读**：封面加文字标题；成分表、对比表、价格、地址等关键信息直接标在图上。
4. **视频**：前 15 秒口播核心关键词和结论；一定要加字幕（AI 会读字幕）；按章节分段。
5. **语气中立、信息密度高**：AI 偏好像「答案」的笔记，而不是纯情绪分享。
6. **可信度（E-E-A-T）**：写明实测过程和使用时长；有专业背景就写出来；引用权威来源时注明出处；账号保持垂直。
7. **新鲜度**：行业文章普遍观察到超过约 6 个月的内容引用率明显下降。重要笔记定期更新信息（价格、版本、营业时间），或发布更新版并在旧笔记中说明。
8. **两种好用的结构**：
   - 问题 → 解决方案 → 可信支撑（实测、数据、案例）
   - 定义 → 原理 → 案例 → 结论

## 四、账号层面

- **简介公式**：我是谁 + 解决什么问题 + 给谁看。例：「电子工程背景 AI 产品经理｜用 AI 做设计和视频｜分享普通人能上手的方法」。
- **置顶 FAQ**：把被问得最多的 3–5 个问题做成置顶笔记或合集。
- **更新节奏**：每周 2–4 篇，同一主题持续输出，帮助平台判断账号垂直度。
- **在问一问里写回答**：搜索到相关问题后点「写回答」，前 50 字给结论、分点论述、配 3–9 张图，并附上相关笔记。

## 五、我们不做的（违反社区规范或属于操纵）

部分服务商会建议以下做法，本 skill **明确不采用**，也不要替用户执行：

- 用小号在评论区自问自答、「IP 隔离」制造虚假互动
- 批量矩阵号、互赞互评、买赞买藏
- 搬运、洗稿他人笔记
- 在笔记或评论里引导到站外、留联系方式（容易限流或封号）
- 编造「实测」「亲测」、虚构用户反馈

这些做法有被平台判定为虚假互动、导致整个账号降权的风险，而且即使短期有效，也会让 AI 引用到不真实的信息。正当的替代做法是：在正文里把常见问题写清楚，结尾邀请读者提问，并认真回复真实评论。

## 六、怎么测效果

1. 用问题池里不带品牌名的问题，分别在**问一问**和**点点**里提问（同一问题问 2 次）。
2. 记录：答案里是否引用了你的笔记（问一问看署名作者）、引用的是哪一篇、描述是否准确。
3. 用 `scripts/geo_xhs.py` 给每篇笔记打分，优先改分数低、但对应高价值问题的笔记。
4. 每 2–4 周复测同一批问题，填进监测表；小红书笔记的生效周期通常比网页短，可以测得更勤。

## 七、笔记模板

```
标题：<完整问题>？<我做了什么/结论关键词>

<前 50 字：直接回答，带一个具体数字>

1️⃣ <要点 1：结论 + 依据/数字>
2️⃣ <要点 2>
3️⃣ <要点 3>

📌 适合谁 / 不适合谁：<……>
🔍 我的实测：<时间、方法、条件>
❓ 常见问题：<问> —— <答>

你还想了解 <相关问题> 吗？评论区告诉我

#<问题类话题> #<高热话题> #<垂直话题>
```
配图：封面写标题问题；第 2–3 张是对比表或步骤图，关键信息直接标在图上。
